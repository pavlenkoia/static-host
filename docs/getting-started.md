# Быстрый старт

[Навигация](README.md) · [Конфигурация](reference/configuration.md)

Требуются GNU Make, Go 1.27.4 или новее, Node.js 24 и свободный порт 8081. Для разработки создайте корневой `.env` и задайте в нём `STATIC_HOST_ADMIN_PASSWORD` длиной 12–72 байта:

```sh
cp .env.examples .env
chmod 600 .env
# Отредактируйте .env и задайте пароль, затем:
make dev
```

`make dev` загружает `.env` в окружение, устанавливает зависимости из lockfile, собирает интерфейс и запускает Go-сервер. Файл читается как shell-файл: значения с пробелами, `$` или `#` заключайте в одинарные кавычки; не помещайте в него команды. Не коммитьте `.env`. В dev базовый домен принудительно отключён, поэтому значения домена и ноды для Compose не мешают локальному входу. Адрес и каталог данных можно задать в `.env` через `STATIC_HOST_LISTEN` и `STATIC_HOST_DATA_DIR` (по умолчанию `127.0.0.1:8081` и `./data`). Остановка — Ctrl+C. Сам Go-бинарник `.env` автоматически не читает.

## Вход и первый сайт

Откройте `http://127.0.0.1:8081/`, войдите как `admin` с паролем из `.env` и создайте ключ агента. Подключите его к `http://127.0.0.1:8081/mcp` через `Authorization: Bearer <ключ>`.

Публикация выполняется агентом: создать сайт → создать upload → передать архив HTTP PUT → вызвать `sites_publish`. Полные параметры и ограничения — в [справочнике MCP](reference/mcp.md). Кабинет показывает сайты и позволяет безвозвратно удалять их.

Локальные адреса сайтов имеют вид `http://<slug>.localhost:8081/`. На другом устройстве `.localhost` указывает на него самого, а не на ваш сервер. Доступ по сети и ограничения HTTP описаны в [конфигурации](reference/configuration.md).

## Проверка запуска

```sh
curl --noproxy '*' http://127.0.0.1:8081/healthz
```

Ожидаемый ответ — `ok` и перевод строки. Остановка — Ctrl+C или SIGTERM. Перезапуск завершает все браузерные сессии, но сохраняет ключи MCP. Проверки изменений — в [разработке](development.md).
