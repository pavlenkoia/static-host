# Инфраструктура и рабочий процесс

Локальная основа на Go слушает loopback `127.0.0.1:8081` по умолчанию; порт задаётся флагом `--port`. Доступны health, Vue-кабинет владельца и MCP с ключами агентов; сессии и хеши ключей хранятся в SQLite. Сборка и ограничения описаны в [локальном этапе](/sources/local-owner-mcp.md). Хостинг сайтов и развёртывание пока не реализованы. Uncloud разворачивает сервис, не каждый пользовательский сайт. Основной процесс не получает Docker/Uncloud sockets и SSH. Отдельная привилегированная роль для доменов предложена, механизм синхронизации ещё не выбран. Генерируемый Caddyfile вручную не редактировать.
Новые токены зашифрованы в SQLite; файл `agent-key-encryption.key` требуется сохранять вместе с базой при переносе и резервном копировании. Процесс с доступом к обоим файлам может раскрыть токены.

Наблюдения 2026-11-25: Uncloud 0.21.0, машины edge-1 и uc-1; Caddy caddy:2.11.7 работает единственной репликой на публичном edge-1; Uncloud volumes отсутствуют. edge-1 имеет 1 CPU, около 1 ГБ RAM и 11 ГБ свободного диска. Ресурсы uc-1 не исследованы. Настроенный кластерный домен был uc.tiangroup.su, а не новый проектный uc.afbmarket.ru. Wildcard DNS и DNS-модуль Caddy не проверены.

Предложенное размещение на edge-1 не обеспечивает HA. Uncloud не выполняет автоматическое rescheduling. Нужны постоянные данные и резервная копия вне edge с проверкой восстановления; backup не заменяет пользовательский rollback.

Документация — docs/architecture.md; правила — корневой AGENTS.md. Локальная wiki — стандартная .llm-wiki/. Начинать запрос знаний с index.md, затем секционных индексов. Raw-снимки неизменяемы; новые источники импортировать через okf ingest, изменения записывать через okf update с timeline и log. Подключение инструкций выполнено через okf wire --agent codex. Основание исправления: [стандартное подключение OKF](/sources/agent-workflow-correction.md). Wiki не является вторым независимым архитектурным контрактом.

Тесты обязательны: до завершения изменения выполнить `make check` (сборка Vue, Go-тесты с race detector без кэша и Playwright на настоящем Go-сервере с временной БД). Узкие проверки при разработке не заменяют итоговый gate. GitHub Actions запускает его на push/PR; для блокировки merge отдельно требуется обязательный статус Required checks в защите ветки. Подробнее — [обязательные проверки](/sources/development-checks.md). Изменения production/DNS и разрушительные действия требуют разрешения. Проверка документации: `okf index .llm-wiki`, затем `okf lint .llm-wiki --strict-frontmatter`.

Основание: [начальные решения](/sources/project-decisions.md). Связанные страницы: [модель продукта](/notes/product-and-publication.md), [домены](/notes/domains-and-security.md).
