# Разделение проверок CI и браузерных E2E

Решение владельца: браузерные тесты в GitHub Actions на каждом push и pull request расходуют лишние время и ресурсы. На этих событиях запускать сборку интерфейса и Go-тесты с race detector. Браузерные E2E запускать локально перед завершением изменений интерфейса и вручную в GitHub Actions. `make check` остаётся полным локальным gate.
