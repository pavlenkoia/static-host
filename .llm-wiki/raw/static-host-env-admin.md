# Единственный администратор: пароль окружения

Пользователь утвердил замену ручной инициализации владельца обязательной переменной STATIC_HOST_ADMIN_PASSWORD. Логин фиксирован: admin. Пароль 12–72 байта, без значения по умолчанию; отсутствие или некорректная длина блокируют запуск. Пароль не сохраняется в SQLite и логах. Owner init/reset-password удаляются без совместимых обёрток. Смена пароля — изменение runtime-секрета и перезапуск. При каждом запуске аннулируются браузерные сессии; существующие MCP-ключи и ключ шифрования сохраняются. Пароль не нужен CI сборки и не попадает в образ. Окружение контейнера доступно через docker inspect привилегированному оператору; .env должен быть закрытым и вне git. Новая установка не требует отдельного bootstrap базы.
