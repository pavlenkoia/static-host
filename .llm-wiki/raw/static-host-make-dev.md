# Локальный запуск make dev

По запросу пользователя добавлен make dev. Команда требует .env в корне, загружает его как shell-файл с экспортом переменных, выполняет npm ci и сборку интерфейса, запускает Go-сервер. Для локального входа базовый домен принудительно отключён; адрес и каталог данных берутся из окружения либо стандартные loopback:8081 и ./data. Вход admin с STATIC_HOST_ADMIN_PASSWORD. Go-бинарник сам .env не читает. .env не коммитить, хранить с закрытыми правами, значения со спецсимволами заключать в одинарные кавычки. Production и CI не меняются.
