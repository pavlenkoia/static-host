# Ручной выпуск контейнера

2026-11-25 пользователь утвердил только ручной запуск workflow Container image. Автоматическая сборка образа на push и pull request отключена из-за стоимости и избыточной частоты. Workflow запускается через workflow_dispatch; job разрешён только для refs/heads/main, другие refs пропускаются. Перед публикацией остаются make check-fast, сборка linux/amd64 и контейнерный smoke. GHCR получает sha-<полный SHA> и latest. Deploy не выполняется. Остальные workflows этим изменением не затрагиваются.
