# Документация static-host

static-host принимает готовые статические сайты через MCP и публикует полный снимок файлов. Сейчас реализован кабинет одного владельца; собственные домены, история содержимого и rollback отсутствуют.

## Правила сопровождения

- Описания текущего поведения сверяются с кодом и конфигурацией; планы находятся в `roadmap/`, датированные наблюдения — в `history/`.
- При изменении контракта обновляются соответствующий справочник и инструкции. Новая страница добавляется в эту навигацию.
- Команды выполняются из корня репозитория, если явно не сказано иное. Примеры доменов и нод не являются значениями по умолчанию.
- Команды production, DNS и TLS требуют отдельного разрешения. Наличие инструкции не разрешает её выполнение.
- `docs/` — документация для людей; `.llm-wiki/` — проектная память агентов с источниками и историей решений, не второй независимый контракт.
