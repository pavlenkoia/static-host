# Браузерные тесты только локально

Решение пользователя от 2026-11-25: браузерные проверки админки не нужны в GitHub Actions; админка не является главным или критичным компонентом. Удалён workflow `.github/workflows/browser.yml`. Локальные Playwright-тесты и `make check` сохранены. CI сохраняет `make check-fast`, сборку контейнера, smoke и публикацию образа в GHCR.
