# Локальный кабинет и MCP

> Source: `raw/README.md`

Локальный этап: один владелец, Vue-кабинет, SQLite и отдельные отзываемые ключи агентов для MCP. Ключ даёт полный доступ, публикационных инструментов пока нет. Порядок сборки, инициализации и сброса пароля описан в исходном README. Go SDK v1.8.0 требует явного выбора протокола 2025-11-25 для стандартного ping из-за ошибки метаданных в версии 2026-07-28.
