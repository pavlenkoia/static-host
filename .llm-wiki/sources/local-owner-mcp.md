# Локальный кабинет и MCP

> Source: `raw/README.md`

Локальный этап: один владелец, Vue-кабинет, SQLite и отдельные отзываемые ключи агентов для MCP. Ключ даёт полный доступ, публикационных инструментов пока нет. Первоначальная CLI-инициализация заменена [паролем окружения](/sources/env-admin.md): фиксированный admin, обязательный STATIC_HOST_ADMIN_PASSWORD, сброс браузерных сессий при старте без отзыва MCP-ключей. Go SDK v1.8.0 требует явного выбора протокола 2025-11-25 для стандартного ping из-за ошибки метаданных в версии 2026-07-28.
