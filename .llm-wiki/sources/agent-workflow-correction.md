# Правила агентов и стандартное подключение OKF

> Source: `raw/AGENTS.md`

По замечанию владельца исправлено имя файла инструкций на `AGENTS.md`, локальная wiki перенесена из нестандартной `docs/wiki/` в `.llm-wiki/`. Архитектурная документация остаётся в `docs/`. Подключение к инструкциям выполнено штатной командой `okf wire --agent codex`; этот источник импортирован через `okf ingest`.

Агент начинает запрос знаний с локального index.md, следует секционным индексам и использует OKF search. Новые источники импортируются CLI, изменения смысла фиксируются через timeline и log. Исторические raw-снимки сохранены, их прежние пути не являются текущими инструкциями.

См. [рабочий процесс](/notes/infrastructure-and-workflow.md) и [начальные решения](/sources/project-decisions.md).
