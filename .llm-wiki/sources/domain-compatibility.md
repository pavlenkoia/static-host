# Проверка совместимости динамических доменов

> Source: `raw/2026-11-25-domain-compatibility.md`

2026-11-25 проверены фактические версии без изменения production: обе ноды Uncloud 0.21.0, Caddy 2.11.7. Исходники тега v0.21.0 на commit `c58108aa829cca4fe3b5f837e0f1918be1687599` подтверждают глобальную конфигурацию, `x-caddy`, `upstreams` и запрет совмещения `x-caddy` с ingress `x-ports`.

На локальном Caddy той же версии и build hash прошли валидация общего конфига и runtime-проверки: приоритет явных маршрутов другого сервиса и панели; отказ неизвестному hostname через `ask`; выпуск локального сертификата новому разрешённому домену после запуска без reload; 404 после удаления разрешения при сохранённом сертификате; сохранение HTTP endpoint `/.uncloud-verify`. Использовались тестовый backend и внутренний CA, не публичный ACME.

Обновление Uncloud для выбранного механизма не требуется. Реального deploy не было. Публичный ACME, DNS, wildcard TLS, межнодовая связь будущего `ask`, итоговый Compose, HTTPS readiness и диагностика приложения не проверены. Production конфиги, DNS и сервисы не менялись. Полный протокол и ссылки на исходники — в raw-источнике, архитектурная запись — `docs/architecture.md`.

Проверка уточняет статус [решения о динамических доменах](/sources/dynamic-domains.md); связанные темы: [домены](/notes/domains-and-security.md), [инфраструктура](/notes/infrastructure-and-workflow.md).
