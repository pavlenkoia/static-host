# Короткие адреса и автономная загрузка

> Source: `raw/architecture.md`

Публичный адрес сайта отделён от внутреннего ID: постоянный slug формируется из имени, кириллица транслитерируется, совпадения получают суффиксы `-2`, `-3`. Slug не переиспользуется после удаления. Существующим сайтам назначаются короткие адреса при запуске; старые ID-hostname сохраняются.

Временный upload URL — самостоятельная одноразовая capability на 15 минут: PUT требует только URL и Content-Type, без общего MCP bearer. Выдавший ключ проверяется до и после приёма. Публикация остаётся отдельной авторизованной MCP-операцией. Эти изменения подготовлены локально; production этим решением не обновляется.

Связанные темы: [домены](/notes/domains-and-security.md), [публикация](/notes/product-and-publication.md).
