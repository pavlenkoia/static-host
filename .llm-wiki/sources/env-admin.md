# Пароль администратора из окружения

> Source: `raw/static-host-env-admin.md`

Единственный владелец входит как `admin` с обязательным runtime-секретом `STATIC_HOST_ADMIN_PASSWORD` длиной 12–72 байта. Пароль не сохраняется в SQLite или логах; отсутствие/неверная длина блокируют запуск. Команды owner init/reset-password удаляются. При каждом старте браузерные сессии аннулируются, MCP-ключи и ключ шифрования сохраняются. Смена секрета требует перезапуска. Секрет не нужен сборке образа; закрытый .env хранится вне git, окружение доступно привилегированному оператору через docker inspect.

Для локальной разработки [make dev](/sources/make-dev.md) загружает корневой `.env`, собирает интерфейс и запускает сервер с отключённым базовым доменом; отдельный export пароля не нужен.
