# Контейнерная упаковка и выпуск

> Source: `raw/container-release.md`

Образ для linux/amd64 собирает frontend перед Go и запускается без root. Compose закрепляет единственный экземпляр за выбранной нодой и задаёт только panel/mcp маршруты. Smoke проверяет работу и сохранность владельца; публикация GHCR ограничена default branch и требует отдельного включения публичной видимости. Инструкция не выполняет развёртывание.
