# static-host

Проект сервиса публикации готовых статических сайтов через MCP. Сейчас реализована только локальная основа: HTTP-сервер с проверкой состояния. Публикация сайтов, MCP, авторизация и развёртывание ещё не реализованы.

## Запуск

Требуется Go 1.27.4 или новее и свободный порт 8080.

```sh
go run ./cmd/static-host
```

Сервер доступен только на `127.0.0.1:8080`. Проверка состояния:

```sh
curl --noproxy '*' http://127.0.0.1:8080/healthz
```

Ответ: `ok` и перевод строки. Остановить сервер можно с помощью Ctrl+C или SIGTERM.
